# APP Plumbing website concept

A responsive, single-page website concept for APP Plumbing, built with plain HTML, CSS and JavaScript.

The page includes a procedural canvas model of a backflow prevention assembly. Visitors can orbit it with a pointer or keyboard, toggle the exploded view and labels, and start or stop rotation.

## Preview locally

Open `index.html` directly, or run a local server from this folder:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

- The quote form is a front-end demo. Connect it to APP Plumbing's inbox or CRM before collecting enquiries.
- Confirm the published phone number, licence details, service areas, availability and review count with the business.
- Replace the stock imagery with APP Plumbing's own job photos where available.
- Add the business's privacy policy and any required legal details.
