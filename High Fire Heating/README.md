# High Fire Heating website concept

Responsive one-page site concept for High Fire Heating Pty Ltd, built with plain HTML, CSS and JavaScript. Its industrial field-service visual system is intentionally separate from the APP Plumbing site.

The page uses a full-bleed field-work hero, service-register layout, credited illustrative stock photo, and custom canvas fire-damper model. Visitors can rotate the model with a pointer or keyboard, animate the blades between open and closed, and show or hide component labels.

## Preview locally

Open `index.html` directly, or run a local server from this folder:

```powershell
python -m http.server 8001
```

Then open `http://localhost:8001`.

## Before publishing to customers

- Connect the preview quote form to the company's inbox or CRM.
- Confirm standards language, service scope, response expectations and service region with the business.
- Replace the illustrative damper model with a product-specific model or real site photography if available.
- Add the business's privacy policy and any required legal details.
